**megaBlog** is a high-performance, feature-packed modern blogging platform built with **React**, **Tailwind CSS v4**, **Redux Toolkit**, **React Router v7**, and **Appwrite BaaS**. It features a modern dark glassmorphic design system, real-time article search and category filtering, rich text editing, secure user authentication, responsive layouts, and built-in interactive demo fallback capabilities.

---

## ✨ Features

- 🎨 **Modern Dark Glassmorphic Aesthetic**: Deep slate backdrop, glowing ambient gradients, frosted glass cards, and smooth CSS transitions.
- 🔍 **Real-Time Article Search & Filters**: Instant full-text search across titles and content, plus tag-based category filtering (`Technology`, `Architecture`, `UI/UX Design`, `Cloud`).
- ✍️ **Rich Text Editor (RTE)**: Integrated TinyMCE editor formatted with dark theme skins (`oxide-dark`) for seamless publishing.
- 🔐 **Authentication & Session Management**: Secure Sign Up, Login, and Session Persistence using Appwrite Account API and Redux Toolkit state.
- 🖼️ **Image Storage & Auto-Previews**: Cover image uploads, automatic image previewing, drag-and-drop file inputs, and Unsplash fallback covers.
- 📱 **Fully Responsive Layout**: Sticky blur navigation header, user profile indicator, and responsive drawer menu for mobile devices.
- ⚡ **Graceful Offline & Demo Support**: Pre-populated sample articles enable immediate testing out of the box even without active Appwrite credentials.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router DOM v7
- **State Management**: Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling**: Tailwind CSS v4, Vanilla Glassmorphic CSS
- **Form Handling**: React Hook Form
- **Rich Text Editor**: TinyMCE (`@tinymce/tinymce-react`)
- **Backend as a Service**: Appwrite (Authentication, Database, Bucket Storage)
- **Build Tool**: Vite 6
